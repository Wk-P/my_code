# v0.0.1 与 v0.1.0 版本对比

## v0.0.1（旧实验代码归档，commit 65c0ea0）

- 标签打于 2026-06-24，作为"旧实验代码"的基线快照，提交信息为 `archive: old experiment code as v0.0.1 baseline`。
- 内容较为庞杂，包含：
  - `README.md`、`.clauderc`、`.python-version` 等项目杂项文件；
  - `ecu_eq_svc_p/experiment/` 下的回调、评估工具、绘图脚本（callbacks.py、eval_utils.py、plots.py 等）；
  - `old-research-code/`：旧的聚合脚本（aggregate_results.py、plot_aggregate.py）、并行运行脚本（run_all_parallel.sh 等）、日志和实验报告（experiment_report*.md/html、experiments_cn_lt.md/html 等）；
  - `old/reports_20260513/{eq,gt,lt}/`：按 eq/gt/lt 三个场景分类的历史报告（config.json、methods.md、parameters.md、reports.md、results.md）；
  - 多个 seed（如 seed_4）下各算法（ppo_mask、ppo_lagrangian、ppo_opt、ddqn、dqn）的原始结果 CSV。
- 定位：**历史实验的完整归档**，代码与报告混杂，包含大量已过时或探索性的脚本。

## v0.1.0（核心实验代码精简版，commit a090f09）

- 标签同样打于 2026-06-24，提交信息为 `feat: v0.1.0 clean core experiment code`，说明中写明：
  > Remove old archives, docs, aggregate scripts, frontend. Keep only ecu_{eq,gt,lt}_svc_p core algorithm files.
- 相较 v0.0.1，共 **753 个文件变更，新增 2007 行、删除 73669 行**，做了大幅精简：
  - 删除了 `old-research-code/`、`old/reports_20260513/` 整个历史归档与报告目录；
  - 删除了旧的聚合/绘图/并行运行脚本；
  - 删除了前端相关内容；
  - 新增/保留 `pyproject.toml`、`requirements.txt` 等标准化项目配置；
  - 只保留三个核心场景目录 `ecu_eq_svc_p/`、`ecu_gt_svc_p/`、`ecu_lt_svc_p/`，每个场景下统一包含：
    - `problem1/`（环境定义 env.py）
    - `problem2_ilp/`（ILP 最优解，config + objects.py + optimal_solution/main.py）
    - `problem3_ppo/`、`problem4_ppo_mask/`、`problem5_ppo_lagrangian/`、`problem6_ppo_opt/`（PPO 系列变体）
    - `problem_dqn/`、`problem_ddqn/`（DQN/DDQN 基线）
    - 公共工具：`run_utils.py`、`timer_utils.py`、`training_steps_config.py`
- 定位：**去粗取精后的核心算法代码**，三个场景（eq/gt/lt）结构完全对称，便于复现和对比实验。

## 后续变化（当前 main 分支，commit 776ecb7）
